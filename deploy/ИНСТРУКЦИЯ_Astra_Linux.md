# Установка сервиса распознавания документов на Astra Linux

Сервис запускается в Docker. После установки интернет не нужен.
Работа — через браузер: http://localhost:8080

---

## Что лежит на флешке (папка `olya_ocr`)

| Файл | Зачем |
|---|---|
| `olya_ocr_image.tar.gz` | сам сервис (образ Docker, ~400 МБ) |
| `install.sh` | установка и запуск одной командой |
| `docker_offline/` | Docker для установки без интернета (запасной вариант, если не получится из репозитория Astra) |
| `ИНСТРУКЦИЯ_Astra_Linux.md` | этот файл |
| `SHA256SUMS.txt` | контрольные суммы — проверить, что файлы скопировались без ошибок |

> Флешка должна быть отформатирована в FAT32/exFAT/NTFS — любой подходит, самый большой файл ~400 МБ.

## Требования к компьютеру

* процессор x86_64 (обычный Intel/AMD), 6 ядер, 16 ГБ памяти;
* свободно на диске: **10 ГБ** под сервис + примерно **2× объём документов** (3 ГБ документов → ещё ~6 ГБ);
* Astra Linux Special Edition 1.7 / 1.8 или Common Edition;
* права администратора (`sudo`).

Все команды ниже вводятся в **Терминале** (меню «Пуск» → Системные → Терминал Fly).

---

## Шаг 1. Проверки (1 минута)

```bash
uname -m
```
Должно быть `x86_64`.

```bash
free -g && df -h /
```
Памяти (`Mem: total`) — 15–16, свободного места (`Avail`) — от 15G.

**Только для Astra Linux Special Edition** — проверить режим замкнутой программной среды (ЗПС):
```bash
sudo astra-digsig-control status
```
* `DIGSIG_ELF_MODE=0` (или команда не найдена) — всё в порядке, идём дальше.
* `DIGSIG_ELF_MODE=1` — ЗПС включена: Astra запускает только программы, подписанные её ключом, и Docker-контейнер
  будет заблокирован. Для этого компьютера ЗПС нужно отключить или настроить исключение — **это решает администратор
  безопасности** (отключение: `sudo astra-digsig-control disable` и перезагрузка).

---

## Шаг 2. Установить Docker (один раз)

Сначала проверьте, может быть Docker уже есть:
```bash
docker --version
```
Если версия напечаталась — переходите к шагу 3.

### Вариант А — из репозитория Astra (нужен интернет или локальный репозиторий предприятия)

```bash
sudo apt update
sudo apt install -y docker.io
sudo systemctl enable --now docker
```

### Вариант Б — без интернета, с флешки

Сначала выполните шаг 3 (скопировать папку), затем:
```bash
cd ~/olya_ocr
sudo bash docker_offline/install_docker_offline.sh
```

Проверка (в обоих вариантах):
```bash
sudo docker info | head -5
```
Должно напечатать `Client:` / `Server:` без ошибок.

---

## Шаг 3. Скопировать папку с флешки

Вставьте флешку — она откроется в файловом менеджере. Скопируйте папку `olya_ocr` в домашнюю папку
(перетащить мышкой) **или** в терминале:

```bash
cp -r /media/$USER/*/olya_ocr ~/
cd ~/olya_ocr
sha256sum -c SHA256SUMS.txt
```
Все строки должны заканчиваться на `OK` (если `FAILED` — файл повреждён при копировании, скопируйте ещё раз).

> Если флешка смонтирована в другом месте — посмотрите путь в адресной строке файлового менеджера.

---

## Шаг 4. Установить и запустить сервис

```bash
cd ~/olya_ocr
sudo bash install.sh
```

Займёт 2–3 минуты. В конце будет:
```
ГОТОВО. Сервис работает.
  Откройте в браузере:        http://localhost:8080
  С других компьютеров сети:  http://192.168.x.x:8080
  Результат распознавания:    /opt/olya_ocr/output/chunks.jsonl
```

После этого флешка больше не нужна. Сервис **сам запускается после перезагрузки компьютера**.

---

## Шаг 5. Работа

1. Откройте в браузере **http://localhost:8080**.
2. Перетащите в окно файлы и папки с общего диска (можно вперемешку, вложенные папки подхватываются)
   или нажмите «выберите файлы» / «выберите папку». Нажмите **«Загрузить и распознать»**.
3. Распознавание идёт само. Можно закрыть браузер — работа продолжится. 3 ГБ сканов — это несколько часов
   (скорость показывается на странице).
4. Блок **«Ошибки»** показывает проблемные файлы сразу, как только они встретились
   (повреждён, защищён паролем, пустой, плохое качество скана…).
5. Блок **«Проверьте слова»** — слова, в которых система не уверена, с картинкой из скана.
   Впишите правильное слово → Enter. Если слово верное — «оставить как есть».
6. Когда всё готово — кнопка **«Скачать результат»** или папка **`/opt/olya_ocr/output`**.

### Результат

Для следующего этапа (поиск и ответы LLM) нужен **один файл: `/opt/olya_ocr/output/chunks.jsonl`** —
весь текст, разбитый на фрагменты, у каждого указан исходный файл и страница.
Рядом лежат `documents/` (полный текст каждого документа) и `report.xlsx` (отчёт об ошибках).

Скопировать результат на флешку:
```bash
cp -r /opt/olya_ocr/output /media/$USER/*/результат_ocr
```

### Если загружать через браузер долго

Документы можно положить прямо в папку `/opt/olya_ocr/input` (или подключить туда сетевой диск) —
на странице появится ссылка «Распознать документы из подключённой папки сервера».
```bash
sudo cp -r /путь/к/документам/* /opt/olya_ocr/input/
```

## Управление

| Что сделать | Команда |
|---|---|
| Остановить | `sudo docker stop olya_ocr` |
| Запустить снова | `sudo docker start olya_ocr` |
| Посмотреть, работает ли | `sudo docker ps` (в строке olya_ocr — `Up ... (healthy)`) |
| Журнал работы | `sudo docker logs --tail 50 olya_ocr` |
| Обновить версию | положить новый `olya_ocr_image.tar.gz` и снова `sudo bash install.sh` (данные сохранятся) |

Пауза распознавания (например, на рабочий день) — кнопка «Пауза» на странице.
Если компьютер выключили посреди работы — после включения распознавание продолжится с того же места.

**Начать всё с нуля** (удалить все загруженные документы и результаты):
```bash
sudo docker rm -f olya_ocr
sudo docker volume rm olya_ocr_data
sudo rm -rf /opt/olya_ocr/output/*
cd ~/olya_ocr && sudo bash install.sh
```

## Если что-то пошло не так

| Сообщение / ситуация | Что делать |
|---|---|
| `permission denied ... docker.sock` | команда без `sudo` — добавьте `sudo` в начало |
| `Docker не установлен` | шаг 2 |
| `port is already allocated` / `address already in use` | порт 8080 занят: `sudo PORT=8081 bash install.sh`, адрес будет http://localhost:8081 |
| `мало места на диске` | освободите место (нужно от 10 ГБ + объём документов) |
| Контейнер запускается и сразу останавливается, ошибки `Operation not permitted` / `permission denied` при запуске | включена ЗПС (шаг 1) — к администратору безопасности |
| Вариант Б: `failed to start daemon` / ошибки про `iptables` | `sudo apt install iptables` (есть на установочном диске Astra) и повторить |
| С другого компьютера страница не открывается | включён межсетевой экран: `sudo ufw allow 8080/tcp` (если ufw используется) |
| Компьютер сильно тормозит | уменьшить число процессов: `sudo WORKERS=3 bash install.sh` |
| Что-то другое | выполните `sudo docker logs --tail 100 olya_ocr > ~/olya_ocr_log.txt` и пришлите файл |
